Tipos de estilos en CSS

Estilos en linea

Se van a agregar directamente en el elemento HTML mediante el atributo style pero puede dificultar la mantenibilidad del código si se abusa de esta técnica.

Este parrafo tiene estilos en linea

Estilos internos

Estos estilos de agregame en el mismo archivo HTML dentro de la etiqueta style en la sección <head> y para gregarlos se utiliza el elemento <style>.

Estilos externos

Estos estilos son los que se recomiendan utilizar ya que ofrecen modularidad, facilidad de mantenimiento, orden, eficiencia entre otras ventajas. Para agregar una hoja de estilos externa dentro de la etiqueta <head> se utiliza el elemento <link> donde especificaremos la ruta al archivo CSS y usamos el atributo rel establecido en "stylesheet" y el atributo href apuntando a la ubicación del archivo CSS.
