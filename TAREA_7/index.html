Resumen HTML: Principales conceptos y etiquetas

Esta pagina va a resumir los principales conceptos y etiquetas vistas en la clase de programación web

Conceptos principales HTML

HTML

HTML (HyperText Markup Language) es el lenguaje de marcado de hipertexto estándar. ES un lenguaje de marcado que se utiliza para estructurar páginas web.

Elemento HTML

Un elemento HTML Es la unidad basica de estructura y contenido en una pagina web.

  1. Etiqueta de apertura
  2. Pares Atributos-valor
  3. Contenido del elemento
  4. Etiqueta de cierre

Etiqueta <head>

La etiqueta head es un elemento HTML que se utiliza para comunicarse con el navegador atraves de los metadatos, permite mejorar, el SEO, ademas se enlaza archivos externos de estilos o scripts.

Etiqueta <body>

La etiqueta body es un elemento HTML que contiene todo el contenido que ve el usuario en nuestra pagina web.

Contenedores Semanticos

Etiqueta Descripción
<header> Etiqueta utilizada para el contenido introductorio de una pagina web, puede tener el logo, el menu de navegación, el nombre de la empresa, etc.
<nav> suele contener enlaces adicionales a otras paginas o navegar por la pagina principal.
<main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje pSrincipal del sitio web,, dentro se colocara el contenido principal de nuestra pagina.
<section> Es una etiqueta que poco a poco se intenta que sutituya a <diiv>, su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado.
<article> Etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido, sigue teniendo coherencia, normalmente se compone de un encabezado y contenido.
<footer> Etiqueteta que normalmente se encuentra al final de la pagina y funciona como cierre del sitio web, a menudo tiene datos de contacto, derechos de autor, u otra informacion.
<aside> Representa contenido secundario que no está directamente relacionado con el contenido principal.
<aside> Representa una seccion cuyo contenido no esta relacionado con el contenido principal del documento como barras laterales, publicidad, enlaces a otros articulos relacionados etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces a otra pagina

  • Externos
  • Internos
  • Anclaje

algunos valores especiales que tiene en su atributo href son:

href = "https://wa.me/2821825617"
Este valor envia un whatsapp a un numero especifico
href = "mailto:example@example.com"
Este valor abre el cliente de correo predeterminado del usuario para enviar un correo electrónico a la dirección especificada.
